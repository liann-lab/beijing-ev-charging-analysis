# 2025 年 1 月与 7 月的充电订单量和利用率变化

Figshare 发布版 2，清洗运行 `20261104T011749595890Z`。逐网格计算 7 月减 1 月，两个月均有保留订单的 2,239 个网格进入比较。仅在 1 月有订单的 78 个网格和仅在 7 月有订单的 317 个网格未纳入配对。

订单按开始月整笔归属。网格利用率为纳入统计的订单时长之和，除以网格内有保留订单的站点配置枪数之和与当月分钟数的乘积。两个月均为 31 天。利用率变化用百分点表示。地图采用匿名相对坐标，红色表示上升，蓝色表示下降。两张地图和散点图均覆盖全部配对网格，颜色和散点横轴使用对称对数尺度以同时显示大小变化。

| 变化方向 | 网格数 |
| --- | ---: |
| 订单量与利用率均上升 | 1,791 |
| 订单量上升、利用率下降 | 204 |
| 订单量下降、利用率上升 | 43 |
| 订单量与利用率均下降 | 187 |
| 至少一项持平 | 14 |

订单量在 1,995 个网格上升，利用率在 1,838 个网格上升。逐网格变化的中位数分别为增加 281 笔和增加 2.33 个百分点，变化的 Spearman 秩相关为 0.724。两个月均至少有 5 把纳入统计的枪时，1,987 个网格中仍有 1,621 个同时上升、172 个订单量上升但利用率下降，秩相关为 0.730。

订单增量最大的网格为 `9897_4437`（+48,313 笔），利用率升幅最大的网格为 `9914_4433`（+34.04 个百分点）。在订单增加但利用率下降的网格里，`9893_4445` 的订单增量最大（+14,016 笔，利用率 −2.34 个百分点）。该网格纳入统计的枪数从 120 到 202，增加 68.3%，而订单总时长增加 49.1%，所以用总时长除以枪时得到的比率下降。统计中的枪数变化取决于当月有哪些站点有订单，实际新增设备需要另行核实。以上结果描述两个观测月份的变化。
